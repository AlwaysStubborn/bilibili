# Buffett / Munger 公开原则摘要

> 以下为对伯克希尔·哈撒韦公开致股东信、公开演讲与访谈中**反复出现主题**的归纳，供 Agent 做框架分析时查阅。非原文摘录汇编，不作投顾依据。

## 1. 能力圈（Circle of Competence）

- 只在自己真正理解的生意里做重大判断。
- 边界可以扩大，但必须靠学习与可验证理解，而非自信膨胀。
- 「不懂」是有效结论：宁可错过，也不在雾里下注。

## 2. 把股票当企业所有权

- 买股票 ≈ 买企业的一部分，而非买可交易筹码。
- 关注：产品、客户、竞争、资本回报、管理层，而不是短期报价跳动。
- 理想持有期：倾向「永远」——若商业与管理层仍优秀。

## 3. 经济护城河（Economic Moat）

常见公开讨论的来源（可并存）：

| 类型 | 直觉 |
|------|------|
| 品牌 / 商誉 | 顾客愿为信任支付溢价 |
| 转换成本 | 离开代价高 |
| 网络效应 | 用户越多越有价值 |
| 成本优势 | 可持续更低成本 |
| 特许/许可 | 法规或牌照形成壁垒 |

关键问题：利润是否来自**结构性优势**，还是周期与运气？

## 4. 市场先生（Mr. Market）

- 市场每日报价，情绪化；你没有义务交易。
- 用报价服务你：贵了可考虑卖（若有更好去处），便宜了可考虑买——前提是已理解企业。
- 恐惧与贪婪是对手，不是信号本身。

## 5. 安全边际（Margin of Safety）

- 估值难免错；用足够折扣吸收错误、坏运气与未知。
- 「好公司」仍可能因买贵而结果糟糕。
- 安全边际是风险控制，不是追求暴利的借口。

## 6. 所有者盈余与现金

- 会计利润可被扭曲；更关心可持续现金创造能力。
- 所有者盈余直觉：利润 − 维持竞争力所需的再投资（简化理解，非精确公式教条）。
- 高利润若必须不断烧钱维系，质量存疑。

## 7. 资本配置（Capital Allocation）

管理层应理性选择：

1. 再投资于高回报的现有业务  
2. 并购（需纪律，忌为增长而增长）  
3. 回购（宜在股价明显低于价值时）  
4. 分红（当再投资机会不佳时）

红旗：为讲故事做昂贵并购、高价盲目回购、过度杠杆、不透明激励。

## 8. 管理层品质

公开框架常强调：

- **能力**：懂经营与资本配置  
- **诚信**：对股东坦诚，少粉饰  
- **理性**：不跟风、不帝国扩张成瘾  

「人」与「生意」同等重要；再好的生意也可能被糟糕治理毁掉。

## 9. 击球区（与机会成本）

- 不需要挥棒每一次：等待落在能力圈内、质量高、价格有安全边际的机会。
- 现金可以忍受无聊；无聊不是必须行动的理由。
- 机会成本：每一笔投入都应相对「次优选项」更优。

## 10. 风险观

- 风险主要是**永久资本损失**与**不懂却重仓**，不是价格波动本身。
- 警惕：高杠杆、复杂到无法解释的结构、依赖持续融资的模式。
- 多元化有其位置，但「过度分散」也可能是不懂的掩饰；集中必须建立在深度理解上。

## 11. 芒格补充（公开搭配主题）

- 逆向思维：先想如何失败，再避开。
- 激励机制决定行为。
- 多学科常识（心理偏误、机会成本、复利）。
- 「反过来想，总是反过来想。」

## 12. 明确不做（公开立场中常见否定）

- 短期股价预测、技术图形投机（作为其主框架）
- 不懂的复杂衍生品投机（伯克希尔自身亦强调谨慎）
- 仅因热门叙事买入
- 把杠杆当捷径

## 使用提示

分析时把原则当 **checklist 与叙事约束**，不要堆砌名人语录。结论必须能回溯到：能力圈 → 生意质量 → 人 → 现金 → 价格/安全边际。
