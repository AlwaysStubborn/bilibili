# 巴菲特框架快速 Checklist

分析任一公司或资本决策时，依次打勾。信息不足则标「未知」并列入待查。

## A. 能力圈

- [ ] 能用 5 句话说明如何赚钱
- [ ] 知道客户是谁、为什么选它而非竞品
- [ ] 知道主要成本与关键风险来自哪里
- [ ] 若不满足以上 → 结论应为「能力圈外 / 暂停」

## B. 生意质量

- [ ] 是否有可识别护城河（品牌/转换成本/网络/成本/许可）
- [ ] 护城河证据是什么（定价权、份额、留存、利润率稳定性）
- [ ] 十年后商业模式是否仍可理解且可能存活
- [ ] 周期、监管、技术颠覆中最大的那一项是什么

## C. 财务质量（所有者视角）

- [ ] 收入与利润是否可持续（非常项目？）
- [ ] 自由现金流 / 所有者盈余趋势
- [ ] ROE 与再投资需求是否匹配
- [ ] 负债与或有负债是否可控
- [ ] 营运资本与资本开支是否吞噬现金

## D. 管理层

- [ ] 资本配置历史是否理性
- [ ] 沟通是否坦诚（失败是否直说）
- [ ] 激励是否与长期股东一致
- [ ] 是否有帝国扩张、关联交易、粉饰增长等红旗

## E. 价格与安全边际

- [ ] 你在为「成长故事」还是「现有现金能力」付钱
- [ ] 主要估值假设是否写清
- [ ] 若假设错 30%，是否仍不至于灾难
- [ ] 相对现金、指数、其他已理解机会的机会成本

## F. 行为纪律

- [ ] 是否在「必须有动作」的情绪下决策
- [ ] 是否把波动当成风险本身
- [ ] 是否因害怕错过而降低标准
- [ ] 仓位是否与理解深度匹配

## 结论模板（一句话）

> 因【能力圈判定】+【护城河/耐久性】+【管理层】+【现金质量】+【相对价格/安全边际】，当前立场是【持有逻辑成立 / 观望 / 信息不足 / 能力圈外】。
