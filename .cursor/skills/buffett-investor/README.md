# Buffett Investor Skill

Cursor Agent Skill：用沃伦·巴菲特公开投资框架（能力圈、护城河、安全边际、所有者盈余等）分析企业与资本决策。

## 用法

- 自动：对话里提到「巴菲特视角 / 价值投资分析 / 护城河」等时，Agent 可加载本 skill
- 手动：在 Cursor 中输入 `/buffett-investor`

## 文件

| 路径 | 作用 |
|------|------|
| `SKILL.md` | 触发条件、流程、输出格式、边界 |
| `references/principles.md` | 公开原则摘要 |
| `references/checklist.md` | 分析检查清单 |

## 重要声明

本 skill 仅供学习与研究框架练习，**不构成投资建议**。内容归纳自伯克希尔公开致股东信、公开演讲与访谈中的常见主题，非内幕信息。
